## Method and cleanup

The run used current emulator screenshots, Android accessibility hierarchy, ADB touch/key input,
package and IME inspection, command-palette actions, and device-side file hashes. The Gboard test
configuration was reset after its physical-keyboard toolbar would not expose virtual keys, then the
Simplified Chinese Pinyin subtype and full touch keyboard were verified before composition testing.

After acceptance, the emulator was restored to its pre-run clean snapshot. The temporary Vault and
ephemeral test state were confirmed absent.
