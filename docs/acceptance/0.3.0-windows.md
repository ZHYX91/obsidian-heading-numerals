- Plugin 0.3.0 reloaded enabled with no captured runtime or console errors.
- The settings root rendered four Obsidian-native navigable pages and zero custom `tablist`
  elements, matching Property Order, Chrono Notes, and Link Integrity on Obsidian 1.13.4.
- The General page displayed `跟随 Obsidian`, native dropdowns/sliders, and no custom top tabs.

  number format.

  are recognized. The configured default remained template cleanup.

  control change saved successfully, was restored to `auto`, and reproduced the original
  `data.json` byte for byte. A scheduled text-control change transitioned from `scheduled` to
  `saved`, was restored, and also reproduced the original file byte for byte.

  became visible with that exact error, Retry was visible and enabled, retry succeeded after the
  persistence function was restored, and the row hid again in `saved` state. The original
  `data.json` was restored byte for byte.
- Source-core files were unchanged from 0.2.0; the 0.2.0 Windows record remains the dated runtime
  evidence for Live Preview, Reading View, parser safety, commands, and conceal behavior.
