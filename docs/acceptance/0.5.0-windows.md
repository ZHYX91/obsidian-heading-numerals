## Cases passed

- Obsidian loaded Heading Numerals 0.5.0 with the new current-note panel command and ribbon entry.
- A ribbon click opened the panel instead of changing display state or writing a note. The panel
  showed the active note name/path and Global, Current note override, and Effective value columns.
- Virtual numbering, stored-number concealment, scheme, ignore, Restore all, four quick actions,
  batch navigation, and global settings navigation were present in the compact panel.
- A real Properties selection wrote a note override while preserving aliases and the unrelated
  `acceptance-keep` property. No default or empty override was written merely by opening the panel.
- The default-theme desktop layout remained readable at the normal window width. The responsive
  summary change is limited to narrow screens and does not replace the desktop four-column table.

## Method and tooling boundary

Validation used the isolated Vault, exact asset and `data.json` hashes, visible screenshots, Windows
window automation, and a real Obsidian 1.13.4 process. The app ran at 200% display scaling; after a
coordinate replay targeted the wrong foreground window, further coordinate guessing stopped. The
final post-cleanup bundle differs from the fully interacted candidate only by removal of three
unused translation entries; the final asset was installed byte-for-byte and the exact same source
passed the automated and Android cold-start gates.

## Explicitly open

- macOS, Linux, third-party themes, and multi-window/pop-out behavior were not repeated for 0.5.0.
- Folder/Vault batch rollback was not repeated in this UI pass.
- No candidate asset was deployed to the formal Vault during this acceptance pass.
