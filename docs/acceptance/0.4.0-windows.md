  visually replaced by one computed number without changing the source, while ambiguous prefixes

## Method and tooling boundary

Interaction evidence came from visible Windows UI automation, the Obsidian 1.13 CLI, renderer
inspection, screenshots, source hashes, and Obsidian error buffers.
One rejected internal `setMode` harness call produced an Obsidian error because the harness supplied
the wrong internal object; the Vault was reloaded and buffers were cleared before product cases
continued. No plugin exception followed.

## Explicitly open

- This candidate is a dirty working tree, not a tagged or pushed 0.4.0 release.
- U+2060 source markers remain experimental and disabled by default. Outline, anchors, copy,
  external-editor, normalization, malformed-marker, and strip-marker escape-path acceptance remains
  release-blocking before any marker-enabled claim.
- macOS, Linux, third-party themes, and a 2,000-heading interactive latency run were not exercised.
- Batch folder/Vault rollback and concurrent-edit recovery were not repeated in this UI pass; their
  automated coverage is not a substitute for the remaining runtime matrix.
- No new runtime asset was deployed to the formal Vault during this acceptance pass.
