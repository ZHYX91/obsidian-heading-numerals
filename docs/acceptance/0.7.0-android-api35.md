## Method and cleanup

The run used the existing clean Android 15/API 35 emulator snapshot, current screenshots, visible
touch input, package and IME inspection, command-palette actions, and device-side hashes. It used a
throwaway Vault and did not open or modify an ordinary Vault.

closed with snapshot saving disabled, leaving the clean source snapshot unchanged.
