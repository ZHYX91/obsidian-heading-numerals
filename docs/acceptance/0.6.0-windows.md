## Cases passed

- Live Preview and Reading View rendered `1 First`, `1.1 Body`, and `1.2 Next`. Virtual numerals
  were visibly quieter than real heading text without looking disabled.
- `References` and its `Book` descendant were unnumbered. The next sibling resumed at `1.2`, so a
  skipped subtree neither consumed nor reset the active counter.
- `2026. References` remained unchanged and unnumbered. The low-confidence year-like prefix was not
  stripped merely to make an exclusion rule match.
- The custom-scheme editor used a single-column layout. It displayed the exact-title rule,
  `整个章节` scope, removal control, and `当前笔记命中 1 个：References` live preview.
- The real Write preview contained only First, Body, and Next. It separately warned that the
  suspicious `2026.` prefix would be preserved.
- Applying Write produced the previewed source. A second real Obsidian operation cleaned the three
  inserted prefixes and restored the exact original Markdown source.

## Method and tooling boundary

Validation used the isolated Vault, exact asset hashes, visible screenshots, Windows UI Automation,
and a real Obsidian 1.13.4 process. Computer Use was attempted first; its bundled runtime exposed
window discovery but not the documented control context, so UI Automation and exact window handles
were used for the remaining interactions.
