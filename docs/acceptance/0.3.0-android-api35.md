## Cases passed

- Plugin trust, enablement, settings persistence, process restart, background/foreground, and
  landscape rotation completed without a plugin exception.
- Obsidian mobile 1.12.7 heading syntax nodes were captured from the live CodeMirror tree. The
  precise mobile form is covered by the editor adapter and regression tests.
- Virtual numbering rendered in Live Preview and Reading View; the H2-start scheme produced
  `1`, `1.1`, and `2`. H1 remained unnumbered, `3.14` was not double-numbered, and fenced code was
  unchanged.
- Conceal mode hid recognized stored prefixes in Live Preview and Reading View while preserving
  the source file byte for byte.
- Current-note source mutations are unavailable in Reading View. In editing mode, previewed write
  inserted `1`, `1.1`, and `2`; previewed cleanup restored the exact original SHA-256.
- Real Pinyin keyboard taps created the `ce shi` preedit and `测试` candidate. Composition did not
  change the file, candidate commit inserted `测试` inside an H2, and one editor undo restored the
  exact original file hash.
- The automated gate passed with 14 test files and 73 tests after the mobile adapter and
  edit-mode mutation guard were added.
