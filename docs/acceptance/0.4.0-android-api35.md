## Method and tooling boundary

Android interaction used visible emulator screenshots plus ADB input, UI hierarchy, package
metadata, source hashing, and logcat. The Chinese case used the actual Fcitx composition pipeline
rather than injected final text.

## Explicitly open

- This is emulator evidence, not physical Android-device acceptance. iOS was not exercised.
- Rotation, background memory pressure, Samsung/Pixel vendor keyboards, hardware keyboards, and
  third-party mobile themes remain open.
- U+2060 source markers remain experimental and disabled by default; the cross-tool marker matrix
  remains incomplete.
- Batch folder/Vault mutation and recovery were not run on Android in this pass.
- No new runtime asset was deployed to the formal Vault during this acceptance pass.
